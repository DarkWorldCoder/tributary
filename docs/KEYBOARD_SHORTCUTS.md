# Keyboard shortcuts

Open **Settings → Keyboard shortcuts**. Automatic layout uses Command on Mac and Ctrl on Windows/Linux; a manual layout choice is also available. Keyboard shortcuts are local to this installation and work while the app has focus.

Click a command's key combination, press the new combination, then **Save shortcut**. Existing combinations report a conflict. **Unassign**, per-command reset, and **Reset shortcuts** are available. Each platform layout keeps its own assignments.

Choose **Enter** or **Ctrl/⌘+Enter** to send messages. Shift+Enter adds a line. The send button remains available on touch devices.

| Default | Action |
| --- | --- |
| Ctrl/⌘ + Shift + O | New chat; Ctrl/⌘+N remains an alias |
| Ctrl/⌘ + K | Search chats and commands |
| Ctrl/⌘ + B | Toggle sidebar |
| Ctrl/⌘ + J | Toggle workspace |
| Ctrl/⌘ + Shift + E / D / M / P | Files / Changes / Memory / Preview |
| Ctrl/⌘ + backtick | Terminal |
| Ctrl/⌘ + Alt/Option + O | Recent files and folders |
| Ctrl/⌘ + Alt/Option + T / R / A | Agent team / Project room / Live activity |
| Ctrl/⌘ + comma | Settings |
| Ctrl/⌘ + slash | Shortcut reference |
| Shift + Escape | Focus the message box |

Editor and terminal bindings stay with their own tools. Editor Save uses Ctrl/⌘+S; Format uses Shift+Alt+F; Wrap uses Alt+Z. Those tool-owned bindings are listed separately and are not reassigned by the app shortcut recorder. Tab and Escape retain focus-navigation behavior. International AltGr typing is not intercepted. Browsers and operating systems may reserve combinations; this is not a system-wide hotkey service.

Phone and tablet users can use visible actions or a hardware keyboard. The renderer has been checked at 320–1920 px; Mac/Windows matching and labels have automated coverage, with simulated Command input in Linux Electron. Native macOS, Windows and physical mobile keyboards remain untested.
