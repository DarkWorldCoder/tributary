# Tributary: next UX opportunities

Research date: 3 November 2026. Audience: people using one or several coding agents, including people who need help reviewing unfamiliar code. Scope: desktop task continuity, change review and tool discovery; near-term product decisions rather than a market-size study.

## Executive read

The strongest opportunity is helping people reconstruct what happened: the task, the working directory, the changes and the evidence behind completion. Public issue reports describe loss of worktree-path context and difficulty accessing older conversation history. Other reports describe a configured or connected MCP server whose tools are unavailable to the session. Those are distinct reliability and setup problems, with a common interface consequence: the person cannot tell which state to trust. Tributary already has handoff summaries, project memory, diff review, tool activity and team workflows, so the next additions should connect and explain those capabilities. This scan supports prioritizing inspectable state and review receipts over adding more decorative controls; it does not establish how often Tributary users experience these problems.

## Opportunity map

- **This week:** ship the compact environment/context panel and All features finder; make project/branch and existing memory evidence easy to reach; finish image preview, zoom and editor controls. These are UI changes delivered in this pass, with validation recorded separately.
- **This quarter:** implement context/review receipts, a real per-agent MCP availability probe and resumable task checkpoints. Prototype line-linked review comments using the existing diff and message identifiers.
- **Needs deeper research:** per-conversation working copies, merge/conflict ownership across multiple developers, safe worktree cleanup and interruption recovery. Validate repository-level behavior before adding UI that promises isolation or automatic recovery.

## Source map and limits

Public web queries covered GitHub issue trackers, Reddit discussion results, developer forums and research-paper results. Primary issue reports above carry the recommendations; anecdotal discussion results were used to identify themes, not frequency or market demand. Queries aimed at Hacker News and Stack Overflow did not produce enough direct, product-specific evidence to contribute to the ranking. X was not searched, and no authenticated internal/support sources were accessed. Agent Reach's Exa endpoint was unavailable in this environment, so the accessible web-search tool was used as the fallback. No saved Product Design context existed; the provided screenshots and current Tributary source were the design grounding.

Internal observations are limited to this conversation's requests and the local implementation. The new context panel shows recorded memory characters/sources and configured MCP entries. It does not fabricate token-window percentages, connection health, remote-control support or worktree guarantees. Research recommendations are separate from implemented capabilities.
